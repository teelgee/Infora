# ADR-0011 - The project library is the sole knowledge corpus; owner-curated; auto-admits accepted deliverables; decouples WIP storage from knowledge

**Status:** Accepted.

**Context:** "AI knowledge layer" was doing double duty. Drafting assistance wants a user's messy working context; knowledge retrieval must not ground on unfinished drafts (wrong content) or the DRR (review opinion, not fact). A trust line was needed. The sandbox-versus-SharePoint-mirror question hinged on the wrong assumption that the AI grounds on the sandbox.

**Decision:** A project has a project library: the curated, owner-controlled corpus of trusted project knowledge. It is the real-world MIDP generalised beyond transmitted deliverables. Accepted deliverables enter the library automatically on acceptance, since acceptance is already the trust decision. The owner may also add other material (reference documents, standards, baseline data) by deliberate action, and may segment or withhold parts of the library for IP or ethical-wall reasons, so membership and visibility are owner-defined. Both AI purposes ground only on the library: the chat agent answers project questions from it, and the Word drafting agent grounds new text on it. Neither reads the raw sandbox nor the DRR. The DRR remains a workflow surface the AI operates on as a task (clustering, drafting candidate responses, flagging duplicates), never a knowledge source.

**Consequences:** Trust comes from a curation decision, not from file location. Work-in-progress storage (native Infora sandbox or SharePoint mirror) is decoupled from knowledge quality, because the AI never grounded on the sandbox; it becomes a product and adoption choice, not a build-1 knowledge blocker (closes the open part of the sandbox-mirror question). A mid-draft document is invisible to the knowledge layer simply because it is not in the library; if an owner wants a not-yet-accepted document to be groundable, they add it to the library rather than us inventing a second trust flag. Library segmentation ties into the access model and ethical walls. Builds on ADR-0005 (acceptance) and the access model.
