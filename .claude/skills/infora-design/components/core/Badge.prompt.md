Scannable single-word state in dense lists and on cards.

```jsx
<Badge tone="success">Current</Badge>
<Badge tone="warning">In review</Badge>
<Badge tone="neutral" pill>Member</Badge>
```

Flat (dot + text) in tables; `pill` (tinted background) on cards. Tones map to meaning: success = accepted/current, warning = awaiting, danger = rejected/failed, info = external authority, neutral = no state.
