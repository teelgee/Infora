The document review record

Every comment on the deliverable, consolidated in one place: one table that spans every round, each comment carrying its location, its code, its author and the response that answered it, and each round closed off by the deliverable code it concluded with. A further round appends to the same table rather than starting a fresh sheet. Both sides open the same record — but the wall shapes what each of them reads, which is the second screen.

Design decisions in this mockup
One table, appended to — not a sheet per round Rounds are bands inside one record, not separate tables or tabs. The chapter's whole review history reads top to bottom in one scroll, which is the thing the Excel review notice could never do and the reason ADR-0009 refused to materialise one.
Each round closes with its code A round ends on a verdict band carrying the deliverable code, who set it and when. Round 2 carries a band saying it has no code yet, because an open round with no verdict is a state, not a gap — and no count of comments will ever fill it.
The wall is a different record, not a hidden column Screen 2 does not grey out round 2's rows — it does not have them. The withheld notice states that content exists and why it is out of reach, which is the house rule: silence would read as absence, and absence is a different and wrong fact.
No export, deliberately There is no download, no "issue the record", no print-to-PDF button anywhere on this screen. ADR-0009 dropped the DRN and refused a second artifact; a button here would quietly reinstate it. The browser can still print, which is a browser doing its job rather than Infora issuing a document.
The response points at the change A response either carries a "Changed in P02" pointer or an explicit no-change with its reason. There is no third state and no blank cell — an unanswered comment reads "awaiting the authoring side", which is a round state rather than a silence.
Open — where this screen lives Needs your yes/no. Drawn as its own Review pane reached from the deliverable, with "Open the round" as the way through to the PDF and the commenting surface. The alternative is a tab on the existing cycle screen. This way the record is a place you can send someone; the other way it is a view of a screen.
